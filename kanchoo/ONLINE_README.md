# MONSTER WAR オンライン対戦版

## 1. 必要なもの

Node.js 18以上をインストールしてください。

## 2. サーバー起動

`server` フォルダで以下を実行します。

```bash
npm install
npm start
```

起動後:

`http://localhost:8080/title/title.html`

をブラウザで開きます。

Windowsなら `start-server.bat` をダブルクリックしても起動できます。

## 3. 2人で対戦する

1. PLAYER 1側でゲームを起動し、ルーム画面へ進む。
2. ROOM IDを確認する。
3. PLAYER 2側で同じルームURLを開く。
   - 例: `http://localhost:8080/room/room.html?room=ABC123`
4. それぞれ「対戦卓」を選択する。
5. 両者が「準備」を押す。
6. 自動的にBATTLEへ移動する。
7. ターン制で操作を同期する。

## 4. 現在のオンライン通信

サーバーはWebSocketで以下を同期します。

- ルーム参加
- 対戦卓のPLAYER 1 / PLAYER 2
- READY状態
- 選択パーティ
- BATTLE開始
- ターン
- キャラクター位置
- HP / 生存状態
- 技使用結果
- ブラフ使用状態
- 行動終了
- 勝敗状態
- バトルログ

BATTLEでは、現在のターンプレイヤーだけが操作できます。

## 5. インターネット対戦

現在の構成は「Node.jsサーバー + WebSocket」です。

同じPCでの動作確認は `localhost` でできます。

インターネット越しに対戦する場合は、この `server` を外部公開できるNode.jsホスティングへ配置し、HTTPS環境ではWSSを使用してください。

ゲーム本体はサーバーから静的配信する構成なので、`kanchoo` フォルダ全体をそのまま配置できます。

## 6. 注意

現段階では、サーバーは「ターンの所有者」と「状態の順序」を管理し、ゲーム状態そのものはクライアントが計算して送信します。

そのため、完成版として公開する場合は、最終的にはサーバー側で移動可能マス・技の射程・ダメージ・勝敗などを検証する「サーバー権威型」にするのが適しています。
